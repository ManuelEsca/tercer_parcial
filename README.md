# tercer_parcial
El proyecto consiste en desarrollar una página web turística interactiva utilizando los lenguajes HTML, CSS y JavaScript.

El objetivo principal es crear un sitio web atractivo, moderno y fácil de utilizar, donde los usuarios puedan conocer información sobre diferentes destinos y atractivos turísticos, acompañada de imágenes y elementos interactivos.

Tecnologías utilizadas
HTML: Para crear la estructura y contenido de la página.
CSS: Para diseñar y dar estilo al sitio web.
JavaScript: Para agregar funciones e interactividad.
Objetivo

Aplicar los conocimientos adquiridos durante el tercer parcial en el desarrollo de una página web relacionada con el turismo, utilizando herramientas digitales para presentar información de manera organizada, visual y atractiva.
